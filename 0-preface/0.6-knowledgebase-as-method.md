# 0.6 The Knowledgebase as Method

> ◉ **Public edition.** This note is published in a redacted public edition. Personal contact details, private third-party specifics, and passages resting on the author's private records are excluded, and each exclusion is disclosed where it is made. The private sources themselves (correspondence, family records, the mail archive) are held by the author and are not part of the public repository.

**Question:** Explain the method behind the series: a ~40-year personal collection of books, articles, transcripts and notes; made queryable "in earnest" ~7 years ago via RAG (retrieval-augmented generation) when the GPT-3 API appeared; now 14,000+ curated documents in the appliedanthropology / seculardharma knowledgebases, accessed via the wah.id interface (DrAA / MyDharma agents) and CLI; how this corpus underpins the DD essay series itself; and Indonesia's deep Sanskrit / "Hindu" cultural substratum in which "dharma" is just one more embedded, hand-wavey loanword.

## Synthesis

The DD essay series is written *from* a corpus that is also one of its subjects. The author describes a ~40-year personal collection — "books, articles, transcripts, my own random notes" — made genuinely queryable "in earnest" only when the GPT-3 API appeared, by wiring it for retrieval-augmented generation: ask a question, retrieve the most relevant passages, let an LLM synthesise an answer grounded in those sources [S1]. RAG has a precise founding paper (Lewis et al., NeurIPS 2020) and the GPT-3 API a precise launch date (11 June 2020), which dates the project's "in earnest" turn to mid-2020 — about six years before this 2026 essay, so the "seven years" is a fair round-up, not a measurement [S2][S3][S4]. The pile has since grown into the `appliedanthropology` / `seculardharma` knowledgebases — the same vectors under two personas — holding ~14,000 documents and ~170,000 searchable chunks, queried via the wah.id web interface (the DrAA and MyDharma agents) for quick passes and a CLI for serious work [S1][S5][S6][S7]. The corpus is self-describing in a strong sense: it physically contains the author's own notes (801 documents), cleaned-up sangha transcripts (2,342 transcript documents), the named influence shelf as primary texts, an account of RAG itself, and the anthropology of the very Indonesian Sanskrit substratum the preface invokes — in which *dharma* is a documented, fully naturalised loanword [S5][S8][S9][S10][S11][S15][S16]. The instrument and the evidence are the same object, which is exactly what a citation-disciplined method has to confront here.

## Findings

### The method: a long collection made queryable by RAG

The author's own account, in private correspondence, is the primary source for the method's origin: "the secular dharma KB started in earnest ~ seven years ago, but the underlying collection has been with me for forty: books, articles, transcripts, my own random notes" [S1]. The turning point was the GPT-3 API: "when the GPT-3 API was released i signed up [and] started to make this pile actually queryable, using RAG (retrieval-augmented generation); you ask a question, then the system pulls the most relevant passages from the corpus and an LLM synthesises a coherent answer using the sources" [S1].

That workflow is **Retrieval-Augmented Generation**, introduced by Patrick Lewis et al. (2020), *Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks*, accepted at NeurIPS 2020 (arXiv:2005.11401, 22 May 2020) [S2]. The paper defines RAG as combining "pre-trained parametric and non-parametric memory for language generation" — a generator coupled to "a dense vector index" accessed through "a neural retriever" — motivated by the fact that although LLMs store knowledge in their weights, "their ability to access and precisely manipulate knowledge is still limited" [S2]. In practice the pipeline splits documents into overlapping chunks, embeds each chunk as a vector, stores the vectors; at query time it embeds the question, retrieves the most semantically similar chunks, and supplies them as context to the generator — which "mitigates the hallucination problem by anchoring outputs in retrieved information" [S3]. The corpus contains a plain-language explanation of exactly this technique (chunk → embed → vector DB → retrieve relevant chunks → LLM synthesises), a neat instance of the corpus describing its own instrument [S8].

**Dating the "in earnest" turn.** OpenAI announced the GPT-3 API on 11 June 2020 as a request-access private beta, roughly two weeks after the GPT-3 paper's preprint of 28 May 2020; the waitlist was removed only in November 2021 [S4]. TechCrunch reported the same launch (11 June 2020) as an API for "virtually any English language task," initially gated to about a dozen partner companies [S12]. So "signed up the day the GPT-3 API was released" places the RAG turn at mid-2020 — about six years before this 2026 essay. The author's "about seven years" is therefore a rounded-up but fair gloss on a ~6-year interval [S1][S4].

### What "queryable by meaning" actually rests on (FAISS + dense embeddings)

The retrieval engine named in the configuration is **FAISS** [S6]. FAISS (Facebook AI Similarity Search) is "an open-source library for similarity search and clustering of vectors," developed by Meta AI (originally Hervé Jégou, Matthijs Douze and Jeff Johnson); it offers exhaustive and approximate nearest-neighbour search at billion scale, with CUDA/GPU acceleration, written in C++ with Python wrappers [S13]. The foundational GPU paper is Johnson, Douze & Jégou (2019), *Billion-scale similarity search with GPUs* [S14]. This is the machinery doing the dense-vector retrieval over the corpus's ~170,000 chunk embeddings [S5][S6][S13].

The reason the pile is searchable by *meaning* rather than keyword: a text embedding is a dense vector that "captures the semantic meaning of text," positioned so that "texts with similar meanings have similar vector representations"; models in the sentence-transformer family (bge-m3 is one) are trained with contrastive learning to pull similar texts together and push dissimilar ones apart, and retrieval ranks by cosine similarity (≈1 for semantically aligned text), capturing synonyms and related concepts that exact keyword search misses [S9]. The configuration's similarity threshold (0.6) and top-k (30) are this mechanism's tuning knobs [S6].

### The numbers — precise and honest, with the caveat flagged

The "14,000+ curated documents" claim checks out against the live database. The shared `seculardharma.db` (a symlink to `appliedanthropology.db`) contains **14,186 distinct source documents** and **169,758 searchable segments** (chunks): `COUNT(DISTINCT sourcedoc)` = 14,186, total rows in `docs` = 169,758 [S5]. So the author's "over 14,000 curated books, articles and transcripts" is accurate as of this DB state, and refers to *documents*, not segments [S1][S5].

▲ The "777,553" figure carried in the project files is stale and internally inconsistent, and must not be repeated as a document count. The local `seculardharma.cfg` advertises "777,553+ interdisciplinary documents" in both `query_role` and the `long_desc` (where it is explicitly attached to FAISS) [S6]; `seculardharma/CLAUDE.md` repeats "15,224 documents (777,553 searchable segments)" [S7]. Neither matches the current shared DB: documents = 14,186 (not 15,224 and not 777,553), segments = 169,758 (not 777,553) [S5]. The honest statement is therefore ~14,000 documents / ~170,000 segments (live DB), with the cfg and CLAUDE.md carrying an older, larger, internally-inconsistent figure [S5][S6][S7].

**Embedding / search configuration** (the cfg being the citable source of truth for settings, with the caveat below): vector model **bge-m3** at **1024 dimensions**; chunk target 300–500 tokens (`db_min_tokens`/`db_max_tokens`); FAISS vector index; `query_top_k` = 30; similarity threshold 0.6; query model `gpt-5.5`; reranking via `BAAI/bge-reranker-v2-m3` on CUDA. In this dev cfg `enable_hybrid_search` and `enable_query_enhancement` are both **false** — the BM25 keyword index exists but this tree runs pure dense vector search plus reranking. The stopword languages include **Indonesian** (with French/German/Swedish), a small tell of the corpus's locale [S6]. Per the project files, the *canonical* SD runtime is the production deployment, not this dev tree, and the local cfg may legitimately differ; bge-m3 / 1024-d are set "to match whatever the shared AA index was built with" [S7]. So those settings should be read as "this dev tree," not as an immutable fact about production [S6][S7].

### The corpus contains its own instruments and influences

This is the loop closing: the KB is both subject and instrument, and direct file-name inspection of the DB shows it [S5].

- **The author's own notes are in the corpus at scale.** 801 distinct documents carry the `gd_keep` prefix (e.g. `gd_keep-0090` "dharma -- adaptive for what?", `gd_keep-0123` "Recovering Dharma", `gd_keep-0499` "Dharma; Seeking a Cure for the Human Problem"), many tagged with a `broad_context` of "Biology, Evolution, Anthropology, Culture, Dharma, Human Behavioural Evolution." These are the "my own random notes" the author names, folded in and queryable alongside published works [S5][S15].
- **Transcripts are in the corpus at scale.** 2,342 distinct documents match `%transcript%`, including both technical explainers and dharma-talk transcripts. This is consistent with the author's account that the sangha's "~50 videos... transcripts of these talks have been cleaned up and folded into the secular dharma / applied anthropology knowledgebases" [S1][S5]. Sangha member **Rupert Bozeat** appears as a named corpus author (`Rupert-Bozeat/Drawing_Meditation.md`), corroborating the named coterie of Gary, Rupert and Elfie [S15][S1].
- **The named influence-roster is physically present as primary works.** The author's "cast" — "Graeber, Sapolsky, Boehm, Batchelor, Wrangham, Bregman, James Scott, Sarah Hrdy, Lisa Feldman Barrett" [S1] — is in the DB as full source documents: Boehm's *Hierarchy in the Forest* (Harvard, 1999); Graeber's *The Dawn of Everything*; Sapolsky's *Behave* plus lecture transcripts; Wrangham's *The Goodness Paradox*; Bregman's *Humankind*; Lisa Feldman Barrett's *How Emotions Are Made*; Kropotkin (five works); and David Sloan Wilson via a `prosocial.world` dialogue [S16]. The curated lean the DD methodology warns about is not an abstraction; it is the actual shelf [S16].
- **The secular-dharma source material is present and central.** The DB holds a Batchelor / secular-buddhism cluster: his book *Secular Buddhism*; *What is this?* (Martine and Stephen Batchelor); an MBEL interview transcript; the "Ten Theses of Secular Dharma"; and a web-sourced `secular-buddhism.md` in which Batchelor articulates "the core logic of secular dharma" (embrace suffering → non-reactive space → respond to suffering; cultivate a *sangha*) and predicts secular dharma "may very well end up decoupling itself from traditional Buddhism" [S17][S18]. This is the material the preface's Bodhi College retreats (from February 2018) and the email thread refer to [S1][S19].
- **Curation is visible in the directory structure.** Source paths sit under `appliedanthropology/staging.text/` in author/topic folders (`gd_keep_notes/`, `Bodhi/secular_buddhism/`, `Christopher_Boehm/`, `Graeber/`, `Sapolsky/`, `anarchy/`, `prosocial.world/`, `emails/`, `websearch_data/`), confirming that `appliedanthropology` is the superset and `seculardharma` a persona over the same vectors — matching the author's "applied anthropology is the substrate; secular dharma is one of the applications running on top of it" [S15][S16][S17][S1].

### The interface: wah.id, DrAA / MyDharma, and the CLI

The author's account names the access path: "the easiest way in is the web interface at https://wah.id, using either the 'DrAA' or 'MyDharma' agents... the website is good for one-shot (or few shot) queries, but serious research use requires use of a cli terminal," and notes the site was "created mainly for use by my employees" [S1]. The public wah.id site corroborates the apparatus: it brands itself "WAHID — Witty And Honest In Dialogue," an "LLM Workbench" under Okusi-Associates, letting users create and manage conversations with AI agents, configure agent templates and models, adjust temperature (0.7 default) and token limits, "integrate optional knowledgebases," and export conversations as JSON or Markdown [S20]. The specific agents DrAA and MyDharma are not exposed on the public landing view — they remain attested by the local primary email — but the site's framing ("optional knowledgebases," "agent templates") matches the shared-corpus / multi-persona model exactly [S1][S20]. DrAA is the applied-anthropology persona; MyDharma the secular-dharma persona — the same vectors, two system prompts, the shared-corpus fact in the project methodology [S1]. A public YouTube talk, "Crafting Dharmic AI: Aligning AI with dharmic discourses | a secular dharma," frames the project as aligning an LLM with dharmic discourse, tying the MyDharma persona to the method's intent [S21].

### How this corpus underpins the DD series

DD's Stage-1 research is conducted *against* this corpus via the `yatti-api` RAG interface (`seculardharma` / `appliedanthropology`, plus `prosocial`), with web research where the corpus is thin or one-sided — which is precisely how the present note was assembled [S1][S5][S6]. So the knowledgebase is the project's instrument as well as one of its objects: the same vectors that hold the author's own dharma notes, the sangha transcripts and the influence shelf are the vectors DD queries when it researches dharma [S5][S15][S16]. The series is, in this sense, the corpus turned back on itself with a citation discipline imposed — which is also why this note's most load-bearing facts (counts, model, config) had to be checked against the live DB and the cfg rather than taken from a synthesised RAG answer [S5][S6].

### Indonesia's Sanskrit / "Hindu" substratum, with *dharma* as an embedded loanword

The preface's claim — that Indonesia, though now nominally majority-Muslim, has "deep cultural roots imported from India ('Hindu')," with Sanskrit words and cosmology embedded in the language, so that "dharma is just another of those words; every bit as hand-wavey here as it is elsewhere" [S1] — is well supported.

From the corpus: a *Civilisations* passage states that the kingdoms of Southeast Asia adopted India's caste structure, Hindu myths and philosophies, and "perhaps most importantly, the language of Sanskrit," with classical Sanskrit becoming "the language used among the elite of Southeast Asia, just like Greek and Latin were once required learning among Europe's nobility" — and flags Sanskrit as Indo-European (*danta* ~ "dentist"), connecting back to the PIE etymology of *dharma* in [[1.1-etymology]] [S22]. Clifford Geertz's *The Religion of Java* documents the layering of Indic, Islamic and indigenous strands in Javanese religion [S23]; Benedict Anderson's *Java in a Time of Revolution* supplies a glossary thick with Sanskrit-derived Javanese loanwords (*guru*, *ilmu kebathinan*), showing the embedded vocabulary concretely [S24].

External sources close the one gap the corpus left — the philology of the Indonesian word itself. The canonical scholarship is J Gonda's *Sanskrit in Indonesia* (1973) and J.G. de Casparis's *Sanskrit Loan-Words in Indonesian* (1997) — ▲ both cited here at **bibliographic level only**; neither monograph was consulted in full text, and the borrowing-date and semantic-field detail reaches this note through the de Casparis-derived check-list rather than the originals. On that footing: borrowing began with Indian contact "long ago before the 1st century" and permeated religion (*agama*), philosophy (*dharma*) and administration (*raja*) [S10][S11]. The Indic-loanword inventory built on de Casparis lists "*darma, dharma*" with the Indonesian gloss "duty, good deeds (i.e. charity), truth etc.," from Sanskrit धर्म (*dharma*) — the hard attestation that *dharma* entered Indonesian as a Sanskrit loanword and is now an ordinary dictionary word [S11]. Crucially for the "hand-wavey" point, the same inventory notes that Sanskrit loanwords "have entered the basic vocabulary of Indonesian to such an extent that, for many, they are no longer perceived to be foreign," and that of ~25,500 Old Javanese dictionary entries "almost half are Sanskrit loanwords" — i.e. *dharma* is a fully embedded, semantically diffuse loanword, not a marked foreign technical term [S11].

The substratum that carried it in survives in modern Indonesia: Indic culture arrived from ~1st century CE via trade ("Hinduisation"), peaking under the 14th-century Majapahit empire; Bali remains ~87% Hindu, wayang theatre derives from the *Ramayana* and *Mahabharata*, and many Indonesians of any religion bear Hindu names (Wisnu, Surya, Indra, Arya, Putra, Aditya, Sita) [S25][S26]. The 14th-century Old Javanese *kakawin Sutasoma* — which yields Indonesia's national motto *Bhinneka Tunggal Ika* ("Unity in Diversity") — valorises kings as "dharma protectors," making *dharma* a live court concept centuries before the modern state [S26][S27]. So the substratum is not antiquarian but woven into modern Indonesian identity, exactly the "deep cultural roots imported from India" the preface invokes [S1][S25].

## Tensions, gaps & corpus bias

- **The corpus is the instrument as well as the subject — a reflexivity risk.** Several of this note's claims are the corpus describing itself (its RAG-explainer transcript [S8], its own influence shelf [S16], its self-advertised document counts [S6][S7]). That is unusually circular, so the load-bearing numbers were deliberately taken from *outside* the RAG layer — direct SQLite inspection of the shared DB [S5] and the raw cfg/CLAUDE.md text [S6][S7] — rather than from a synthesised RAG answer. (The scholarly RAG endpoint was in fact returning HTTP 502 during the research session, which forced this more citable, count-exact approach.)
- **The curated secular / evolutionary / Western-academic lean is literally the shelf.** The DD methodology flags the corpus as curated around Boehm, Sapolsky, Graeber, Batchelor and Bregman; file inspection confirms all five sit in the DB as primary texts [S16]. So this note's framing of dharma as an evolved cultural technology, and of secular dharma as one application of applied anthropology, reflects the author's own stated thesis and the corpus's composition — not a neutral survey. Non-secular and non-Western framings of the *method* (e.g. traditions that would resist treating dharma as queryable data) are absent by construction.
- **Self-reported biographical claims, flagged as such.** The forty-year collection, the "in earnest ~seven years ago" timing, the GPT-3-API sign-up, the "~50 videos," the sangha membership (Gary, Rupert, Elfie), the Bodhi College retreats from 13 February 2018, and the advanced degree in Indonesian anthropology are the author's own words [S1][S19]; several are uncorroborated by independent sources and are recorded here as self-report, honestly, not as verified fact. The bereavements (his son, 2012; wife Anita, 2015) and the political history (early CPA membership, then anarchist groups including the Freedom Collective in Fremantle) are likewise sourced solely to the author's own words and were deliberately not web-searched or corroborated, per the project's privacy constraint [S19]. The Margolis correspondence is cited for its substance only; all personal contact details have been stripped [S1].
- **The "seven years" is a gentle over-round.** The GPT-3 API launched mid-2020 [S4], so the interval to this 2026 essay is ~6 years, not 7 — the author's "about seven years" is a fair colloquial round-up rather than a measurement [S1][S4].
- **The headline document count in the project files is wrong and inconsistent.** "777,553" appears as a *document* count in the cfg and as a *segment* count in CLAUDE.md, and "15,224 documents" appears nowhere in the live DB [S6][S7]; the only defensible figures are the live ~14,186 docs / ~169,758 segments [S5]. Treat the cfg/CLAUDE.md numbers as outdated marketing copy, not data.
- **A philology gap the web pass closed, with a residual edge.** The corpus established the *substratum* (Geertz, Anderson, Civilisations) but not the loanword philology of Indonesian *dharma/darma*; external sources (Gonda, de Casparis, the Indic-loanword inventory) closed it [S10][S11]. The remaining thin spot is *primary* Old Javanese textual treatment of *dharma* (e.g. the *Negarakertagama*, the Balinese *dharma/adharma* pairing, a KBBI entry for *darma*), which a deeper Stage-2 pass should consult directly rather than via tertiary inventories.
